# 手势控制的 3D 发光粒子生日蛋糕（6 步仪式）

一个单文件网页（`index.html`）：Three.js r160 粒子系统 + MediaPipe Hands 手势识别 + Web Audio 吹气检测，走完 **点燃 → 花束 → 比耶 → 点赞 → 许愿 → 吹灭** 的完整生日仪式，最后跳转专属 3D 贺卡。

纯黑金暗夜视觉，约 20,400 个粒子（`THREE.Points` + 自定义着色器 + AdditiveBlending），60fps 流畅运行。

## 直接打开

双击 `index.html` 即可，无需构建、无需安装依赖（Three.js / MediaPipe 走 CDN）。

摄像头与麦克风在 `https` 或 `localhost` 下最稳；`file://` 也能用，但个别浏览器会限制。

## 六步流程

| 步骤 | 交互 | 兜底按钮 | 画面 |
| --- | --- | --- | --- |
| ① 点燃 | 捏合保持 0.8s | 「点燃蜡烛」/ 点火焰 | 火焰跳起，蛋糕整体提亮 |
| ② 花束 ☝🏻 | 只伸食指、其余三指收拢，保持 0.7s | 「比 1 / 变成花束」 | 粒子平滑变形成 3D 花束，烛火淡出 |
| ③ 比耶 ✌🏻 | 食指+中指伸直，保持 0.7s | 「比耶 / 展开照片」 | 花束散成星空，拍立得照片星环展开 |
| ④ 点赞 👍🏻 | 拇指向上、四指收拢，保持 0.7s | 「回到蛋糕形状」 | 照片飘散，粒子聚拢回蛋糕，烛火重亮 |
| ⑤ 许愿 | **纯点击** | 「愿你愿望成真！」 | 2.8 秒暖金光环 + 祝福动画 |
| ⑥ 吹灭 | 对麦克风吹气约 0.6s | 「吹灭蜡烛」/ 点火焰 | 熄火冒烟、星光炸裂、WISH RECEIVED → 跳转贺卡 |

第 1~4 步可用按钮走完；第 5 步起不再依赖任何手势。

## 花束是怎么做的

`buildBouquetTargets(count)` 按明确的几何结构与粒子占比建模，一次性生成与蛋糕粒子一一对应的坐标 / 颜色 / 尺寸倍率，写入 `aBouquet` / `aBouquetColor` / `aBouquetSize` 三个 BufferAttribute；顶点着色器用 `uBouquet` 在「蛋糕 ↔ 花束」之间插值，**CPU 每帧只改一个 uniform，不重写 BufferAttribute**，所以不掉帧。

| 部件 | 占比 | 构成 |
| --- | --- | --- |
| 玫瑰穹顶 | 55% | 中心 1 朵大玫瑰 + 周围 7 朵放射状外倾；每朵 **5 层杯状螺旋花瓣**（3/5/6/7/8 瓣），内层紧卷近竖直、外层外翻，边缘由 `v²` 上翘形成杯状 |
| 满天星 + 尖叶 | 10% | 花球缝隙里的高亮星点 + 7 片尖叶（中段最宽、叶尖收拢） |
| 包装纸 + 丝带 | 25% | 双层倒锥包装纸（上缘 6 瓣波浪折边 + 加密轮廓粒子）、腰封丝带环、双耳蝴蝶结、两条自然下垂的飘带 |
| 花茎 + 星光 | 10% | 收腰下方 6 根聚拢细茎 + 少量远距离暗星光 |

配色按层与径向渐变：**花心 `#ff4d7d` 深绯红 → 中层 `#ff8fb1` 玫瑰粉 → 花瓣边缘 `#ffe6c7` 香槟金/奶白**；叶 `#52b788/#74c69d`；包装纸 `#d9a46f → #f3cfa4`；丝带 `#ffcf70/#ffb45a`。

整体还会绕 X 轴前倾约 12°（`TILT = 0.21`），展示角度更自然。

调参入口都在函数顶部：

```js
const DOME_Y = 1.70;        // 花球中心高度
const PAPER_TOP_R = 1.04;   // 包装纸开口半径
const BOW_Y = -0.30;        // 丝带位置
const BRIGHT = 0.74;        // 整体亮度（<1 防止叠加混合把颜色冲白）
const TILT = 0.21;          // 前倾角
```

> 叠加混合下密集粒子会互相"冲白"，所以花束模式单独用了更低的核心增益（1.4× vs 蛋糕 3×）和粒子权重，颜色才留得住。

## 麦克风吹气判定

判据不是「够响就算」，而是三层组合，避免说话/环境噪声误触：

1. **自适应底噪门限** —— 安静时缓慢跟随环境噪声，空调/风扇的稳态噪声会被自动扣除；
2. **包络稳定度** —— 最近约 0.27 秒能量的变异系数。吹气是持续气流（起伏小），说话有音节起伏（起伏大）；
3. **频谱平坦度** —— 只作为加分项，不同麦克风频响差异太大，不能当硬判据。

界面有**实时电平条**和**灵敏度滑块**：先看电平条会不会跳（确认在收音），吹不灭就把灵敏度往右拉。

状态栏会给出可操作提示：

- `麦克风不可用：...` → 权限被拒/无设备，用按钮兜底
- `麦克风没有收到声音 ...` → 权限给了但系统没采集到音频
- `音频被浏览器挂起 ...` → 点一下页面任意位置即可

## 许愿特效的生命周期

许愿光环（两圈上升的金环）与星尘螺旋**只在 `wishing` 阶段渲染**：

- 进入 `ready`（第 6 步）时 `finishWish()` 会把 `wishTarget` 与 `wish` 直接归零，并立即 `opacity = 0` / `visible = false`；
- 主循环里还有一层保险：只要 `stage !== 'wishing'`，就停止更新光环位置，并在 0.2 秒内把透明度衰减到 0 后强制隐藏。

所以回到蛋糕吹蜡烛的画面是干净的，光环不会跟着进第 6 步。

## 浏览器要求

Chrome / Edge / Safari 最新版。摄像头手势需要 `getUserMedia`，吹气需要 `getUserMedia({ audio: true })` 与 `AudioContext`。
