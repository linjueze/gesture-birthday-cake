# 手势控制的 3D 发光粒子生日蛋糕（6 步仪式）

一个单文件网页（`index.html`）：Three.js r160 粒子系统 + MediaPipe Hands 手势识别 + Web Audio 吹气检测，走完 **点燃 → 花束 → 比耶 → 点赞 → 许愿 → 吹灭** 的完整生日仪式，最后跳转专属 3D 贺卡。

纯黑金暗夜视觉，约 20,400 个粒子（`THREE.Points` + 自定义着色器 + AdditiveBlending），60fps 流畅运行。

## 直接打开

双击 `index.html` 即可，无需构建、无需安装依赖（Three.js / MediaPipe 走 CDN）。

摄像头与麦克风在 `https` 或 `localhost` 下最稳；`file://` 也能用，但个别浏览器会限制。

## 六步流程

| 步骤 | 手势 | 兜底按钮 | 画面 |
| --- | --- | --- | --- |
| ① 点燃 | 捏合保持 0.8s | 「点燃蜡烛」/ 点火焰 | 火焰跳起，蛋糕整体提亮 |
| ② 花束 ☝🏻 | 只伸食指、其余三指收拢，保持 0.7s | 「比 1 / 变成花束」 | 粒子从三层蛋糕平滑变形成 3D 花束，烛火淡出 |
| ③ 比耶 ✌🏻 | 食指+中指伸直，保持 0.7s | 「比耶 / 展开照片」 | 花束散成星空，拍立得照片星环展开 |
| ④ 点赞 👍🏻 | 拇指向上、四指收拢，保持 0.7s | 「回到蛋糕形状」 | 照片飘散，粒子聚拢回蛋糕，烛火重亮 |
| ⑤ 许愿 🙏🏻 | 双手合十 1.0s，或单手五指并拢静止 1.2s | 「双手合十 / 闭眼许愿」 | 3 秒沉浸倒计时，暖金光环升起 |
| ⑥ 吹灭 | 对麦克风吹气约 0.6s | 「吹灭蜡烛」/ 点火焰 | 熄火冒烟、金色星光炸裂、WISH RECEIVED 弹窗 → 跳转贺卡 |

任何一步都可以用按钮走完；没有摄像头也不影响流程。

## 花束是怎么做的

`buildBouquetTargets(count)` 一次性生成与蛋糕粒子一一对应的花束坐标和颜色，写入 `aBouquet` / `aBouquetColor` 两个 BufferAttribute；顶点着色器用 `uBouquet` 在「蛋糕 ↔ 花束」之间插值，CPU 每帧只改一个 uniform，**不会重写 BufferAttribute**。

花束构成：

- **6 朵花**：斐波那契螺旋排布，每朵用玫瑰曲线 `r = R·|cos(5θ)|` 生成 5 瓣、3 层花瓣，中间高边缘低形成穹顶
- **花茎**：从收口到每朵花的二次贝塞尔曲线
- **叶子**：6 片椭叶，沿径向展开
- **包装纸**：带褶皱的锥面
- **丝带**：腰封 + 蝴蝶结（两个环 + 两条飘带）
- **外围星光**：少量暖金浮点

配色：香槟金 `#ffd89b`、暖玫瑰粉 `#ff8fb1`、柔白 `#fff2e6`、淡翡翠金 `#8fd9a8`、暖金丝带 `#ffb45a`。

想调大小 / 配色，改函数顶部的「布局参数」与「配色」两块即可：

```js
const BLOOM_Y = 1.62;      // 花朵基准高度
const BLOOM_R = 0.50;      // 单朵花半径
const SPREAD_R = 0.80;     // 花朵排布半径
const BLOOMS = 6;          // 花朵数量
const BOUQUET_BRIGHT = 0.68; // 花色亮度（<1 防止叠加混合冲白）
```

> 叠加混合下密集粒子会互相"冲白"，所以花束模式单独用了更低的粒子权重与核心增益，颜色才留得住。

## 麦克风吹气判定

判据不是「够响就算」，而是三层组合，避免说话/环境噪声误触：

1. **自适应底噪门限** —— 安静时缓慢跟随环境噪声，空调/风扇的稳态噪声会被自动扣除；
2. **包络稳定度** —— 最近约 0.27 秒能量的变异系数。吹气是持续气流（起伏小），说话有音节起伏（起伏大）；
3. **频谱平坦度** —— 只作为加分项，不同麦克风频响差异太大，不能当硬判据。

界面有**实时电平条**和**灵敏度滑块**：先看电平条会不会跳（确认在收音），吹不灭就把灵敏度往右拉。

状态栏会给出可操作提示：

- `麦克风不可用：...` → 权限被拒/无设备，用按钮兜底
- `麦克风没有收到声音 ...` → 权限给了但系统没采集到音频
- `音频被浏览器挂起 ...` → 点一下页面任意位置即可

## 浏览器要求

Chrome / Edge / Safari 最新版。摄像头手势需要 `getUserMedia`，吹气需要 `getUserMedia({ audio: true })` 与 `AudioContext`。
