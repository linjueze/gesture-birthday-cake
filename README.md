# 手势控制的 3D 发光粒子生日蛋糕

一个单文件网页（`index.html`）：Three.js 粒子蛋糕 + MediaPipe Hands 手势识别，走完「点燃 → 比耶 → 点赞 → 吹灭 → 跳转专属贺卡」的完整生日仪式。

## 直接打开

双击 `index.html` 即可，无需构建、无需依赖安装。所有依赖走 CDN（Three.js r160、MediaPipe Hands）。

建议用 `https` 或 `localhost` 打开，摄像头与麦克风权限在 `file://` 下也能用，但部分浏览器会有额外限制。

## 流程

| 步骤 | 手势 | 兜底按钮 | 说明 |
| --- | --- | --- | --- |
| ① 点燃 | 捏合保持 0.8 秒 | 「点燃蜡烛」/ 点击火焰 | 火焰跳起，蛋糕整体提亮 |
| ② 比耶 ✌🏻 | 食指+中指伸直、无名指+小指收拢，保持 0.7 秒 | 「比耶 / 展开照片」 | 粒子扩散到最大，照片星环展开并绕中心公转 |
| ③ 点赞 👍🏻 | 拇指向上、其余四指收拢，保持 0.7 秒 | 「回到蛋糕形状」/ 灯箱内按钮 | 照片飘散淡出，粒子聚拢回蛋糕 |
| ④ 吹灭 | 对着麦克风吹气约 0.6 秒 | 「吹灭蜡烛」/ 点击火焰 | 熄火、冒烟、金色星光爆发 |

吹灭后展示祝福卡片，2.5 秒后暗金遮罩渐满并跳转到贺卡地址；卡片上始终有「立即打开贺卡 ✉️」按钮，防止浏览器拦截自动跳转。

## 修改配置

两个常量都在 `index.html` 顶部：

```js
const CARD_URL = "https://3dcards.theliang.com/letter/q03wJXlKqAWf";

const MEMORY_PHOTOS = [
  { url: "https://picsum.photos/seed/cake-01/720/540", caption: "那年冬天的第一块蛋糕" },
  // ...
];
```

- `CARD_URL`：吹灭后跳转的目标地址。
- `MEMORY_PHOTOS`：环绕照片。`url` 留空或加载失败会自动降级为暖色发光卡片，不会报错。

## 麦克风吹气判定

判据不是「响度够大就算」，而是三者的组合，避免说话/环境噪声误触：

1. **自适应底噪门限** —— 安静时缓慢跟随环境噪声，空调/风扇的稳态噪声会被自动扣除；
2. **包络稳定度** —— 取最近约 0.27 秒的能量，算变异系数。吹气是持续气流（起伏小），说话有音节起伏（起伏大）；
3. **频谱平坦度** —— 只作为加分项，因为不同麦克风频响差异太大，不能当硬判据。

界面右侧有**实时电平条**和**灵敏度滑块**：先确认电平条会跳动（说明麦克风在收音），吹不灭就把灵敏度往右拉。

如果情况不对，状态栏会给出可操作的提示：

- `麦克风不可用：...` → 权限被拒或没有输入设备，用按钮兜底；
- `麦克风没有收到声音 ...` → 权限给了但系统没采集到音频（常见于被系统静音、选错输入设备）；
- `音频被浏览器挂起 ...` → 浏览器的自动播放策略限制了 AudioContext，点一下页面任意位置即可。

## 技术要点

- **纯 GPU 粒子形变**：每个粒子存两套坐标（蛋糕形态 / 星云形态），顶点着色器用 `uSpread` 插值，扩散/聚拢零 CPU 开销。
- 约 20,400 个粒子（蛋糕 + 托盘 + 蜡烛 + 火焰 + 烟雾），`THREE.Points` + 自定义着色器 + `AdditiveBlending`。
- 光照、烟雾、吹气导致的火焰偏倒、庆祝爆发全部由 uniform 驱动。
- 照片卡片用 canvas 合成「相纸」（圆角相框 + 配文），朝相机做 Billboard 并叠一点微倾。
- 无摄像头 / 麦克风、CDN 加载失败、图片加载失败均有降级路径，不会空白或卡死。

## 浏览器要求

Chrome / Edge / Safari 最新版。摄像头手势需要 `getUserMedia`，麦克风吹气需要 `getUserMedia({ audio: true })` 与 `AudioContext`。
